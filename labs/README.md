# Labs

This folder contains the hands-on labs for the Low-cost MLOps Practice Platform.

The labs are organized by learning level.

    foundation/      Beginner-friendly MLOps building blocks
    practitioner/    Repeatable local MLOps workflows
    professional/    Production-like local MLOps patterns
    advanced/        Platform engineering and advanced MLOps concepts
    shared/          Setup, cleanup, and troubleshooting guides

## How to Use the Labs

Start with the beginner MLOps notes before running labs.

Recommended notes:

    docs/mlops-notes/01-why-mlops-exists.md
    docs/mlops-notes/02-mlops-core-concepts.md
    docs/mlops-notes/03-mlops-tool-map.md

Sinhala notes:

    docs/mlops-notes/01-why-mlops-exists-si.md
    docs/mlops-notes/02-mlops-core-concepts-si.md
    docs/mlops-notes/03-mlops-tool-map-si.md

Then read the shared setup guide:

    labs/shared/setup-en.md
    labs/shared/setup-si.md

## Lab Rules

Each lab should:

    explain the concept clearly
    start from a clean or minimal state
    create only the resources it needs
    avoid depending on previous lab leftovers
    include verification steps
    include cleanup steps
    include cost notes
    provide English and Sinhala guides where applicable
