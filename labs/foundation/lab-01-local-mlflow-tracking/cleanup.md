# Cleanup - Lab 01

This cleanup guide removes the local files generated by Lab 01.

Lab 01 does not create Docker containers, cloud resources, or Kubernetes resources.

## Stop the MLflow UI

If the MLflow UI is running in a terminal, stop it with:

    Ctrl + C

## Deactivate the Virtual Environment

If your virtual environment is active, deactivate it:

    deactivate

## Go to the Lab Folder

From the repository root:

    cd labs/foundation/lab-01-local-mlflow-tracking

## Remove Generated MLflow and Output Files

Run:

    rm -f mlflow.db
    rm -rf artifacts/*
    touch artifacts/.gitkeep
    rm -rf outputs
    mkdir -p outputs
    touch outputs/.gitkeep

This removes files such as:

    mlflow.db
    artifacts/
    outputs/training_summary.json
    outputs/best_model/model.joblib
    outputs/sample_predictions.csv

## Optional: Remove the Virtual Environment

If you want to remove the Python virtual environment for this lab:

    rm -rf .venv

You can recreate it later using:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## Verify Cleanup

Check generated files:

    ls -la
    ls -la artifacts
    ls -la outputs

Expected result:

    mlflow.db should be removed
    artifacts should only contain .gitkeep
    outputs should only contain .gitkeep

## Cost Note

This lab runs locally.

Expected cost:

    Cloud cost: 0
    Local cost: small amount of CPU, memory, and disk usage

## Safety Note

This cleanup does not remove Docker containers, Docker volumes, Kubernetes clusters, or cloud resources.

Lab 01 does not create those resources.
