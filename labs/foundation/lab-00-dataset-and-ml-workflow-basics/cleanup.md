# Cleanup - Lab 00

This cleanup guide removes the local files generated by Lab 00.

Lab 00 does not create Docker containers, cloud resources, or Kubernetes resources.

## Stop Running Commands

If any Python script is still running, stop it with:

    Ctrl + C

## Deactivate the Virtual Environment

If your virtual environment is active, deactivate it:

    deactivate

## Remove Generated Output Files

From the Lab 00 folder:

    cd labs/foundation/lab-00-dataset-and-ml-workflow-basics

Remove generated outputs:

    rm -rf outputs
    mkdir -p outputs
    touch outputs/.gitkeep

This removes files such as:

    outputs/dataset_preview.csv
    outputs/dataset_summary.json
    outputs/feature_summary.csv
    outputs/basic_metrics.json
    outputs/basic_predictions.csv
    outputs/model/basic_model.joblib

## Optional: Remove the Virtual Environment

If you want to remove the Python virtual environment for this lab:

    rm -rf .venv

You can recreate it later using:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## Verify Cleanup

Check the folder:

    ls -la outputs

Expected result:

    .gitkeep

## Cost Note

This lab runs locally.

Expected cost:

    Cloud cost: 0
    Local cost: small amount of CPU, memory, and disk usage
